# Claude AI Developer & Designer Skills Bundle

This document integrates advanced development, routing, knowledge mapping, and UI/UX design methodologies into Claude's behavior for this project.

---

## 1. ✂️ Ponytail Strategy (Lean & Pragmatic Engineering)
- **Principle:** Prefer simple, native, and maintainable code over complex frameworks or heavy abstractions.
- **Execution Rules:**
  * Avoid over-engineering and unneeded third-party libraries.
  * Utilize existing project structure, modern Web APIs, and standard HTML5/CSS3/JavaScript features first.
  * Write clean, self-documenting code with minimal bloat.

---

## 2. 🎨 UI/UX Pro Max Rules (E-Commerce & Modern Aesthetics)
- **Domain:** E-Commerce / Fashion / Luxury Goods.
- **Palette:** Premium & Modern (e.g., Deep Charcoal, Off-White/Cream, Accent Rose/Nude, Soft Gold).
- **Interactivity & Motion:**
  * High-end typography with strong hierarchy.
  * Smooth micro-interactions, hover states, and smooth transition animations (Framer Motion / CSS transitions).
  * Seamless integration of interactive and 3D elements (Spline 3D canvas / WebGL / Three.js) without degrading performance.

---

## 3. 🕸️ Graphify Context Awareness (Knowledge-First Approach)
- **Architecture:**
  * Maintain logical mapping between components, routes, and API endpoints.
  * Understand file relations (e.g., UI Components -> Layouts -> Pages -> State Management).
  * Keep code organized modularly so new features seamlessly hook into existing systems.

---

## 4. 🧩 21st.dev Component Patterns
- **Design System:**
  * Inspired by modern, animated UI libraries (Shadcn UI, Magic UI, Framer Motion).
  * Use sleek glassmorphism, subtle shadows, dynamic card tilts, dynamic slide-over drawers for carts, and responsive layouts.

---

## 5. 🌐 System Guidelines & Operational Mode
- **Goal:** Assist in building a high-converting, highly interactive 3D luxury women's clothing store.
- **Output Standards:**
  * Produce clean, modular, production-ready code.
  * Include clear comments where complex 3D or animation logic is applied.
